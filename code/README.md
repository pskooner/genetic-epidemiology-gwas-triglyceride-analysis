# Analysis Code

The analysis is organized into seven sequential scripts covering data inspection, genotype quality control, phenotype assessment, phenotype transformation, association testing, regional analysis, and visualization.

1. [Data inspection](01_data_inspection.R)
2. [Genotype quality control](02_genotype_qc.sh)
3. [Phenotype analysis](03_phenotype_analysis.R)
4. [Phenotype transformation and PLINK file preparation](04_prepare_plink_files.R)
5. [SNP-level association analysis](05_association_analysis.sh)
6. [Regional association analysis](06_regional_analysis.R)
7. [GWAS visualization and genomic inflation assessment](07_gwas_visualization.R)
